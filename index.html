Assistente Tcharlles

Aplicativo pessoal de automação de Tcharlles Gomes. É usado apenas pelo próprio dono, para organizar a agenda, os e-mails e os arquivos da sua conta Google. Não é oferecido a outras pessoas.

Política de privacidade

O aplicativo acessa somente a conta Google do próprio dono, com a autorização dele, e apenas os dados necessários para as automações pessoais (agenda, e-mail e arquivos).

  • Os dados não são vendidos, compartilhados nem transferidos a terceiros.
  • Os dados não são usados para publicidade nem para treinar modelos.
  • Os dados ficam apenas nos computadores do dono.
  • A autorização pode ser revogada a qualquer momento em myaccount.google.com/permissions.

O uso de informações recebidas das APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de uso limitado.
